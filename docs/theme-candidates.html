神龍 — 攻殻機動隊テーマ アイコン候補

全アイコンは同一の SVG ラインアイコン（24×24・stroke=currentColor）。3 候補の違いは CSS の皮だけ（色・グロー・枠・フォント・括弧）です。これが「テーマを変える」の正体—— 絵文字を捨て、線画 1 セットに別スキンをかぶせて世界観を出します。各行の右端 薄字が現状の絵文字。

1. 共通の線画セットを作る 主要操作を 16/20/24px の SVG にして、線幅・角丸・余白を揃える。アプリ内ではアイコン名で呼び出す。
2. 意味の対応表を固定する 入力、出力、モデル、分岐、保存、警告などを一度だけ定義する。同じ記号が画面ごとに別の意味を持たないようにする。
3. 世界観は token で着せる 形は流用し、色・発光・枠・フォント・状態 badge を CSS 変数で変える。作品ロゴや既存意匠はコピーしない。
